# Data Structures & Algorithms in C++

A collection of C++ programs created while learning and practicing **Data Structures and Algorithms (DSA)**.

## 📚 Topics Covered

This repository contains implementations and practice programs involving:

- Stacks
- Searching
- Sorting
- Student data operations
- Library management and related operations
- Custom data-structure implementations

## 📁 Programs

| File | Purpose |
|---|---|
| `cust_stack.cpp` | Custom stack implementation |
| `customer_str.cpp` | Customer/string-related practice |
| `lib_ser.cpp` | Library-related searching |
| `lib_sort.cpp` | Library-related sorting |
| `library.cpp` | Library operations |
| `marks_sort.cpp` | Sorting student marks |
| `smart_lib.cpp` | Larger library-management practice program |
| `student_display.cpp` | Display student information |
| `student_search.cpp` | Search student information |

## 🎯 Purpose

The main purpose of this repository is to build a strong understanding of DSA by implementing concepts in code rather than only studying their theory.

The programs are part of an ongoing learning process, so the repository will evolve as new concepts are learned and existing implementations are improved.

## 🛠️ Language

- **C++**
